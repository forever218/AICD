## In practice {#notes}

- Choose the closest level. When a single level cannot describe a complex process, use several markers or add a written note
- A level does not change the publisher's responsibility for the final content. For anything that needs accuracy, expertise, or truthfulness, human review and fact-checking are encouraged
- Tool and model names are not mandatory disclosures; a basic disclosure is possible without naming a provider
- A level is proactive disclosure, not technical certification. AICD does not detect AI, and does not ask anyone to trace past usage
